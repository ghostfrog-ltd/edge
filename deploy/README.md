# Deployment Kit

This folder contains production deployment templates for running Ghostfrog on a single Ubuntu VPS.

Contents:

- `env/.env.production.example`
- `nginx/ghostfrog.conf.example`
- `systemd/ghostfrog-engine.service.example`
- `systemd/ghostfrog-queue.service.example`
- `cron/ghostfrog-scheduler.cron`

- `../docs/deployment/production-checklist.md`
